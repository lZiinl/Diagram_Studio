다이어그램 소스

텍스트를 수정하면 다이어그램이 자동으로 정렬됩니다.

문법 가이드 
// 신호 종류: ID "범례 이름" 색상 선 종류
signal normal "일반 신호" #475569 solid
signal fault "고장 신호" #ef4444 dashed
signal hw "HW 인터페이스" #16a34a dotted
signal diagnostic "진단 신호" #8050cc dashdot
// solid 실선 · dashed 파선 · dotted 점선 · dashdot 일점쇄선

component input "입력" #d9e8fb column 1 {
  unit adc "Drv_Adc" #d6ead0 {
    out voltage "VINVOL_TAIL"
  }
}
component control "제어" #f7ceca column 2 {
  unit led "Appl_Led" #ffebcc {
    in voltage
  }
}
adc.voltage -> led.voltage
// 연결 뒤에 fault 또는 hw로 신호 종류 지정
// column 1~8 · 오른쪽 열로 연결
// 이름의 \n은 줄바꿈 · 색상 #RRGGBB

PlantUML과 유사한 전용 문법입니다. 전체 PlantUML 문법을 지원하지는 않습니다.
