다이어그램 소스

텍스트를 수정하면 다이어그램이 자동으로 정렬됩니다.

문법 가이드 
component "컴포넌트 이름" #dbeafe {
  unit adc "drv_adc\n(SWU101.1)\nASIL A" #d6ead0 io #ffcc80
}
adc -> led : 전송 항목
adc -> led #009900 : 녹색 메시지
led --> adc : 점선 응답
adc <- led : led에서 adc로 전송
adc <-- led : led에서 adc로 점선 전송
space 30

// 주석 · 색상은 #RGB 또는 #RRGGBB
// 이름의 \n은 줄바꿈
// 첫 색상은 유닛, io 뒤 색상은 작은 입출력 박스
// component 없이 unit만 선언해도 사용 가능
// 자기 자신에게 보내는 메시지도 지원

PlantUML과 유사한 전용 문법입니다. 전체 PlantUML 문법을 지원하지는 않습니다.
